# GitHub 統一譯名表

全站一律使用下列譯名（台灣慣用），新增翻譯時請沿用，避免同一個詞出現兩種譯法。

| 英文 | 中文 | 備註 |
|---|---|---|
| Repository | 儲存庫 | |
| Pull request | 拉取請求 | |
| Issue | 議題 | |
| Commit | 提交 | |
| Branch | 分支 | |
| Tag | 標籤 | Git 版本標籤 |
| Label | 標記 | 議題／拉取請求的分類標記，刻意與「標籤」區分 |
| Fork | 分叉 | |
| Star | 加星號／星號 | |
| Watch | 關注 | |
| Follow | 追蹤 | 追蹤「人」用追蹤，追蹤「儲存庫」用關注 |
| Merge | 合併 | Squash and merge＝壓縮後合併；Rebase and merge＝重定基底後合併 |
| Clone | 複製到本機 | |
| Release | 發行版本 | |
| Review / Reviewer | 審查／審查者 | |
| Assignee | 負責人 | |
| Milestone | 里程碑 | |
| Draft | 草稿 | |
| Workflow / Job | 工作流程／作業 | |
| Contributor / Collaborator / Maintainer | 貢獻者／協作者／維護者 | |
| Organization | 組織 | |
| Insights | 洞察 | |
| Discussions | 討論區 | |
| Token | 權杖 | |

保留原文的產品名稱：GitHub、Copilot、Codespaces、Gist、Wiki、README、Dependabot、Webhooks、GitHub Actions（分頁顯示為「Actions 自動化」）。

不翻譯的內容：README 內文、留言、檔名、提交訊息、儲存庫／分支／使用者名稱、議題標題、程式碼（見 `dict-github.js` 的 `GITHUB_ZH_SKIP`）。
